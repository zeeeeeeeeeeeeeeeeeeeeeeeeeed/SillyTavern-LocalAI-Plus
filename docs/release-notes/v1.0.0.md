Первая версия **local.ai+** — интерфейс в стиле character.ai и каталог персонажей для SillyTavern.
*First release of **local.ai+** — a character.ai-style interface and character catalog for SillyTavern. English below.*

### Что внутри
- 🧭 **Раскладка как на c.ai** — меню слева, чаты с аватарками, настройки окном по центру, мобильная версия.
- 🔎 **Каталог «Узнать»** — chub.ai, Pygmalion и RisuRealm, фильтры (язык карточки, жанр, размер, 18+ и др.), добавление персонажа в один клик.
- ✨ **Генератор персоны** — описание своего персонажа по идее в двух фразах.
- 🪄 **Мастер настроек** — ответы на твоём языке, долгая память, шаблон из модели (всё с галочками).
- 🌍 **Русский и English** — выбор при первом запуске.

### Установка
1. Нужен установленный **SillyTavern 1.13+**.
2. Скачай `localai-plus-v1.0.0.zip` ниже и распакуй.
3. Запусти `install.bat` — он сам найдёт SillyTavern.
4. Перезапусти SillyTavern и открой его в браузере.

Подробности и решение проблем — в README на главной странице репозитория.

### What's inside
- 🧭 **c.ai-style layout** — left menu, chats with avatars, centered settings windows, phone layout.
- 🔎 **Discover catalog** — chub.ai, Pygmalion and RisuRealm with filters (card language, genre, size, 18+ and more), one-click character import.
- ✨ **Persona generator** — a detailed persona from a two-line idea.
- 🪄 **Setup wizard** — replies in your language, long-term memory, template from the model (all opt-in).
- 🌍 **English and Russian** — chosen on first launch.

### Install
1. You need **SillyTavern 1.13+** installed.
2. Download `localai-plus-v1.0.0.zip` below and unpack it.
3. Run `install.bat` — it finds SillyTavern by itself.
4. Restart SillyTavern and open it in your browser.
