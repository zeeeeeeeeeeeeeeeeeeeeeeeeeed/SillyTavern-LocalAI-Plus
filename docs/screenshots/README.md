# Скриншоты для README

README показывает эти файлы (имена должны совпадать — чтобы заменить картинку, просто положи новую с тем же именем):

| Файл | Что на нём |
|---|---|
| `main.webp` | Главный экран на ПК: меню слева + чат с персонажем. |
| `catalog.webp` | Каталог «Узнать» с фильтрами и сеткой карточек. |
| `persona-generator.webp` | Генератор персоны с готовой анкетой. |
| `setup-wizard.webp` | Мастер «Рекомендуемые настройки». |
| `mobile-chat.png` | Чат на телефоне. |
| `mobile-catalog.png` | *(по желанию)* Каталог на телефоне — чтобы показать, добавь строку `<img src="docs/screenshots/mobile-catalog.png" ... width="24%">` в оба README. |

Подойдут PNG, JPG или WebP — но если меняешь формат, поправь расширение в `README.md` и `README.en.md`.

## Как снять

- **ПК:** `Win + Shift + S` → выделить область → вставить в Paint → сохранить.
- **Телефон без телефона:** в браузере `F12` → значок телефона (Toggle device toolbar) → выбрать iPhone/Pixel → «⋮ → Capture screenshot».
- Чистая копия SillyTavern для съёмки — ярлык «SillyTavern (витрина для скриншотов)» на рабочем столе (порт 8001).

## Перед тем как снимать

- Скриншоты видны **всем**: никаких личных чатов и персонажей.
- В каталоге выключи «18+» **и пролистай выдачу**: даже без этого фильтра попадаются откровенные аватарки и описания. Нейтральнее всего выглядит жанр «Фэнтези» или поиск `knight`.
- Картинки до ~1 МБ каждая.
