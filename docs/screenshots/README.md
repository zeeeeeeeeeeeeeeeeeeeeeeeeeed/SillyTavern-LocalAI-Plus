# Скриншоты для README

Положи сюда 4 картинки с **точно такими** именами — README подхватит их сам (после того как в README.md и README.en.md убрать строки-комментарии вокруг блока скриншотов, см. docs/PUBLISHING.md).

| Файл | Что снять |
|---|---|
| `main.png` | Главный экран на ПК: меню слева + открытый чат с персонажем (2–3 сообщения). |
| `catalog.png` | Каталог «Узнать» с сеткой карточек (вкладка chub.ai, сортировка «Популярные»). |
| `settings.png` | Любое окно настроек по центру с затемнением (например, «Модель» или мастер «Рекомендуемые настройки»). |
| `mobile.png` | Вид с телефона: чат или выдвинутое меню ☰. |

## Как снять

- **ПК:** `Win + Shift + S` → выделить область → вставить в Paint → сохранить как PNG.
- **Телефон без телефона:** в браузере `F12` → значок телефона (Toggle device toolbar) → выбрать iPhone/Pixel → сделать скриншот кнопкой «⋮ → Capture screenshot».

## Перед тем как снимать

- Скриншоты будут видны **всем**. Не показывай свои личные чаты и персонажей, которых не хочешь светить. Лучше завести пару «витринных» персонажей.
- В каталоге **выключи фильтр «18+»** — на GitHub не стоит выкладывать откровенные аватарки.
- Ширина окна ~1400 px смотрится лучше всего. Картинки до ~1 МБ каждая.
