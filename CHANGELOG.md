## [1.0.0] — 2026-10-22

Первая публичная версия.

### Добавлено
- **Раскладка в стиле character.ai**: меню слева (Создать, Узнать, Мои персонажи, Я, раскрывающиеся Настройки, поиск и список чатов с аватарками), окна настроек по центру с затемнением, мобильная версия (☰ и настройки листом снизу), тёмная тема с «пузырями» сообщений.
- **Каталог персонажей «Узнать»**: поиск по chub.ai, Pygmalion и RisuRealm, фильтры (язык карточки, жанр, размер, свежесть, 18+, запасные приветствия, лорбук), лёгкие превью, страница персонажа, добавление в один клик с открытием чата.
- **Серверный плагин** для каталога: обход CORS, кэш превью, автоматический запасной путь через системный прокси/VPN.
- **Генератор персоны**: описание своего персонажа по идее в свободной форме.
- **Мастер рекомендуемых настроек**: шаблоны из метаданных модели, ответы на выбранном языке, долгая память, настройки генерации для RP.
- **Справка** по всем кнопкам.
- **Два языка: русский и английский** — интерфейс, справка, мастер, промпты для модели и установщик. Выбор языка при первом запуске и в меню «Язык · Language»; язык интерфейса SillyTavern переключается вместе с ним.
- Установщик сам находит SillyTavern на дисках и спрашивает «Ставить сюда?»; если не нашёл — подсказывает перетащить папку в окно.
- Установщик и удаление для Windows (`install.bat`, `uninstall.bat`).
