How to use it

Pick a character in the Chats list in the left menu (on a phone — the ☰ button at the top) and type in the box at the bottom. *Asterisks* mark actions, text without them is speech.

Left menu

+ Create — a new character.
Discover — the character catalog from chub.ai, Pygmalion and RisuRealm. The sliders button opens filters: card language, genre, size, freshness, 18+. Click a character → “Add and start chatting”. Needs internet.
My characters — the list, importing cards (PNG/JSON), editing.
Me (my persona) — your name and description. The “✨ Write a description with AI” button turns a short idea into a detailed profile.
Settings (expand with the arrow):
  AI responses — response length and the model's creativity;
  Model — connection to the AI (a green dot means everything works);
  Template — chat format and system prompt;
  Worlds & lorebooks — facts about the world the character remembers;
  Modules — extensions: memory (Summarize), translation and more;
  Background — the chat background image;
  Preferences — theme, font, interface behaviour;
  Language · Язык — change the interface language;
  Recommended settings — open the local.ai+ setup wizard again.
Settings windows close with the cross, a click outside the window, or the Esc key.

Message box

☰ (left) — chat menu: new chat, all chats, regenerate the reply, continue the reply, delete messages, help.
Magic wand — quick extension actions.
White button — send. While the AI is answering it turns into “stop”.

Messages

Right arrow under a reply — another version of the reply (like swiping on c.ai). The left arrow goes back. On the character's first message, swiping only cycles through the greetings written into the card.
Pencil — edit the message (the character will adapt to your edit).
Three dots — more buttons:
  Translate icon — translate the message (Google Translate, needs internet; the target language is in Modules → Chat Translation);
  Eye — hide the message from the AI (it stays on screen, but the character “forgets” it);
  Checkered flag — checkpoint: save the chat at this point;
  Branch — a separate chat that continues the story from this point;
  Two sheets — copy the text.

If a reply looks strange

Swipe (right arrow) or edit the reply. If the character starts repeating itself in a long chat, start a new chat: ☰ → “Start new chat”.
